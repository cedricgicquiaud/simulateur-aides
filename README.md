# Simulateur d'aides numériques

Indique à une TPE ou une PME d'Île-de-France quelles aides (TP'up, PM'up, Prêt Boost) peuvent financer son projet
numérique, combien, et avec quelles démarches. Le numéro SIREN remplit les réponses sur l'entreprise à partir des
données publiques de l'État (API Recherche d'entreprises).

En ligne : https://cedricgicquiaud.github.io/simulateur-aides/

Estimation : c'est la Région (ou Bpifrance) qui décide. Sources relues le 1er octobre 2026.
